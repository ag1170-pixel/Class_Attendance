Class Attendance — System Architecture

Face-recognition attendance across an iPhone app, a Mac/​server recognition engine, and a shared Supabase cloud database. Recognise a person once, then track them — a mask or a turned head never loses their mark.

Recognition — detect, track, match Review — human confirms; nobody dropped Stored — attendance to the cloud

The accuracy guarantee: a student who appears is either auto-present or flagged needs-review — the only way to be marked absent is to clear no frame of the clip. The teacher review is the final safety net, so no one's attendance is silently lost.

Privacy: face embeddings stay on the device (iPhone) or on the institution's own server; only the present/absent result goes to the cloud. face_template and consent are locked by row-level security.

Same formula everywhere: iPhone (Vision / Core ML) and Mac (SFace / ArcFace) run the identical recognise-once-then-track + dual-threshold rule — only the embedding model differs.
